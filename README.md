# MOCHIVNST

**Governance-only initial commit. Not a research or production release.**

This project is an independent cloud-first research system for Vietnamese equities. Business source code, licensed data, secrets and trading authority are not imported by this bootstrap.

## Write governance

Only the owner-designated active conversation may request a narrowly scoped, revision-guarded writer lease. All other chats remain read-only by project policy. Chat labels alone are not independently authenticated.
